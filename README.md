## Ejecutar

para ejecutar poner en la consola
```bash
./run_jupyter.sh
```

y entrar a: http://localhost:8888

## Salir

para salir pulsar `Ctrl + C` y cuando pregunte 'Shut down this Jupyter server (y/[n])?' presionar `y` y luego `Enter` para confirmarlo
